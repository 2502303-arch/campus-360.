CAMPUS360 - Student Information Management System
=================================================

HOW TO RUN
1. Extract the CAMPUS360.zip file.
2. Open the CAMPUS360 folder.
3. Double-click index.html.
4. The website opens in your browser. No installation or internet connection is required.

DEMONSTRATION LOGIN
Username: admin
Password: admin123
Choose a role from the sign-in dropdown to view its menu permissions.

FEATURES
- Dashboard summary
- Student profile registration, editing, deletion and search
- Course management
- Course enrolments
- Academic records
- Reports and CSV export
- Role and permission overview
- JSON backup and restore
- Help and troubleshooting guide

IMPORTANT PROJECT NOTE
This is a front-end school-project prototype. Data is stored in the browser using localStorage.
It is not connected to a production server or shared relational database. The role selector
demonstrates the intended user experience; real authentication and server-side authorisation
would be required for deployment with actual student data.
